 # Objectives of Git

- Create separate branches to work on new features without affecting the main project.

- Allow multiple developers to work on the same project.

- Restore previous versions of files when needed.

- Identify and resolve conflicts when changes overlap.

- Organize and maintain code changes in a structured way.
 
 # Tools I'm Using

- Git: To track changes and manage different versions of files.

- GitHub: To host repositories online and share projects.

- Visual Studio Code (VS Code): To create and edit Markdown files.

- Markdown: To write and format documentation using .md files.
